# TryHackMe: Junior Security Analyst Intro

## Room Overview
This room introduced the responsibilities of a Junior Security Analyst and provided an overview of the Security Operations Center (SOC) environment.

## What I Learned

### 1. Junior Security Analyst Responsibilities
A Junior Security Analyst monitors security alerts and tickets to identify potentially suspicious activity. They review incoming alerts, investigate possible security concerns, and work under the guidance of senior analysts.

### 2. SOC Team Introduction
I learned about the SOC team environment and how junior analysts contribute to monitoring and handling security alerts.

### 3. Malicious IP Addresses
The room introduced malicious IP addresses and how analysts can investigate them using online resources.

Two resources discussed were:
- AbuseIPDB: Used to check IP address reputation and review reports of potentially malicious activity.
- Cisco Talos Intelligence: Provides IP reputation and location-related information to support investigations.

### Key Takeaways
One of my biggest takeaways was learning that there are online databases that allow security analysts to research IP addresses and identify whether they have been reported for suspicious or malicious activity.
I also learned that users can contribute to cybersecurity by reporting potentially malicious IP addresses through resources such as AbuseIPDB.

### Skills and Concepts Introduced
- SOC fundamentals
- Security alert monitoring
- Ticket handling
- Malicious IP addresses
- IP reputation checks
- Threat intelligence resources

### Personal Reflection
This room helped me understand the responsibilities of an entry-level SOC Analyst and introduced me to resources that analysts can use when investigating potentially suspicious activity.
